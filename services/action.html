Public API / Service

Action Stats API

cdn.bananaofficial.workers.dev is a public service for exposing API endpoints and service functionality that other people and projects can use.

What is it?

The Action Stats API is a public-facing API/service layer. It provides endpoints that can be requested directly by websites, applications, markdown, or other services/apps.

You do not need to be part of Request Timeout to use a public endpoint. If an endpoint is documented here as public, it is intended to be usable by anyone.

How it is structured

Base URL

The service starts at cdn.bananaofficial.workers.dev.

API paths

API functionality lives under /api/.../.

Query parameters

Some endpoints accept values through URL query parameters.

Example endpoint

One currently available endpoint is the action statistics API. It accepts a user query parameter.

GET /api/action-stats/?user=USER

Replace USER with the user identifier you want to query. 

https://cdn.bananaofficial.workers.dev/api/action-stats/?user=USER

Using the API

Because the service is HTTP-based, it can be accessed from practically any language or environment that can make web requests. 

![Action Stats](https://cdn.bananaofficial.workers.dev/api/action-stats/?user=USER)

The exact response format belongs to each endpoint. Check the endpoint documentation before depending on individual fields in your project.

Why does it exist?

The goal is to provide useful, reusable web functionality without requiring every project to implement the same service itself. Endpoints can be added over time as the service grows.
