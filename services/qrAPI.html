API

The endpoint generates a QR code for a GitHub profile.

Endpoint

https://cdn.bananaofficial.workers.dev/api/qr/?user=USER&color=123456
Parameter Required Description
user Yes GitHub username whose profile the QR code should link to.
color No Six-character hexadecimal QR color. Defaults to 000000.

Examples

A few valid endpoint URLs.

Default color

Color is omitted, so the API uses black.

/api/qr/?user=octocat

Custom color

Use a six-character hexadecimal color.

/api/qr/?user=octocat&color=ff6600
